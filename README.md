# 모두의 생기부 영역별 평가 문답집

**모두의 학종 상담 시리즈 ③** · Copyright@All Teachers

2025·2026·2027학년도 학생부종합전형 가이드북 **35개 대학**에서
평가 관련 질문 **977개**와 선배 인터뷰 지면 **64면**을 뽑아 모았습니다.

## 네 갈래로 나눴습니다

| 탭 | 무엇 | 건수 |
| --- | --- | --- |
| 평가 체크포인트 | 대학이 서류를 평가하며 **스스로에게 던지는 질문**. 선생님이 생기부를 읽는 잣대 | 450 |
| 학생·학부모 질문 | 학생·학부모의 물음에 **입학처가 답한 대목**. 상담에서 근거로 | 319 |
| 면접 예상질문 | 가이드북에 실린 면접 예상질문·기출 문항 | 208 |
| 선배 인터뷰 | 합격생 인터뷰 지면. 대학의 평가가 아니라 **학생 목소리** | 64면 |

성격이 전혀 다른 자료라 섞이지 않게 분리했습니다.
체크포인트는 "유난히 소홀한 과목이 있는가", "전공 관련 과목을 이수하기 위해 추가적인 노력을 하였는가"처럼
대학이 평가할 때 확인하는 항목이고, 인터뷰는 합격생이 자기 경험을 말한 것이라 무게가 다릅니다.

## 쓰는 법

생기부를 펼쳐놓고 **평가 체크포인트** 탭에서 영역을 골라 질문을 하나씩 짚어가세요.
그 질문에 답이 되는 기록이 있는지 확인하는 것이 곧 정성평가입니다.
학부모가 물으면 **학생·학부모 질문** 탭에서 검색해 대학이 쓴 문장을 보여주세요.

질문을 누르면 원문 지면이 열립니다. 좌우 화살표·손가락 밀기로 이동하고,
이미지를 누르면 확대됩니다. 휴대폰 뒤로가기를 누르면 앱이 닫히지 않고 목록으로 돌아옵니다.

## 한계

규칙으로 뽑아낸 것이라 표 안에 있거나 스캔 품질이 낮은 지면은 놓쳤을 수 있습니다.
독서활동(2건)처럼 건수가 적은 영역은 자료에 없어서라기보다 추출이 못 잡았을 가능성이 있습니다.
답변은 요약하지 않고 원문 지면을 그대로 보여줍니다. 요약 과정에서 뉘앙스가 바뀌면
상담에서 잘못 전달될 수 있기 때문입니다.
